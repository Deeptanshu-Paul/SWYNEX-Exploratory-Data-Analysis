# SWYNEX - Exploratory Data Analysis

## Task 2

This project performs Exploratory Data Analysis on prepared
training and testing datasets containing symptom-based disease
classification data.

## Dataset

- Training records: 4,920
- Testing records: 42
- Features: 132 symptoms
- Target: prognosis
- Disease classes: 41

## EDA Performed

- Dataset structure analysis
- Missing value analysis
- Duplicate analysis
- Disease/class distribution
- Symptom frequency analysis
- Symptom count distribution
- Correlation analysis
- Training vs testing comparison
- Key insights for future modeling

## Key Findings

1. The training dataset contains a large number of duplicate records.
2. The disease classes are evenly distributed.
3. Symptom frequencies vary considerably.
4. Records contain different numbers of symptoms.
5. Some symptoms show relationships with one another.
6. Most testing symptom patterns overlap with training patterns.
